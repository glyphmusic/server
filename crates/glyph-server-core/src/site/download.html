Good to know

Stable gets tested versions. Latest gets every new version first and can have more bugs. You can switch later in the app under Settings > About > Channel. Going back to Stable there offers the newest stable version.

Windows: run the setup to install Glyph. New versions update the same installation and keep your library and settings. For the portable ZIP, unzip it and run glyph.exe. macOS and Linux: unpack the .tar.gz and run glyph.

Android (preview): open the .apk on your phone and allow installing it. To update, install the new APK over the old one. Android cannot install an older version over a newer one: to go from Latest back to Stable, wait for the next Stable, or uninstall first (this deletes the app's data).

Each release has a SHA256SUMS.txt to check the download. The desktop app updates itself from the same releases.
